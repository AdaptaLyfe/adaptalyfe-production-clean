### Requirement

The user must be able to open the **same chatbot** from:

1. Home page
2. Daily Task page

### Important

Do NOT create two separate chatbot systems.

Use **one shared/reusable chatbot component** and one conversation state/history.

### Home Page

* Keep the existing chatbot button and functionality unchanged.
* User can open the chatbot normally.

### Daily Task Page

* Add the same chatbot button/floating chat icon to the Daily Task page.
* Match the existing chatbot button design, size, position, and styling from the Home page.
* When the user taps it, open the exact same chatbot UI.

### Shared Chat State

The chatbot must maintain the same conversation regardless of which page the user opens it from.

Example:

Home:
User opens chatbot → sends "Help me plan my day"

Then navigates to Daily Task:
User opens chatbot → the previous conversation should still be available.

Daily Task:
User sends another message → when they return to Home, the same conversation should be available.

Do not reset or duplicate the conversation when navigating between pages.

### Daily Greeting

Keep the existing daily greeting logic.

When the chatbot is opened for the first time that day:

**Good morning, Ethan 👋**

**You have 3 things planned today.**

☑️ 9:00 AM – Take medication
☑️ 2:30 PM – Appointment
☑️ 5:00 PM – Pick up groceries

**Want me to help you plan today?**

The greeting should appear only once per day, regardless of whether the user first opens the chatbot from Home or Daily Task.

Example:

* First open from Home → greeting appears.
* Close chatbot.
* Open from Daily Task → greeting does NOT appear again.
* Next day → greeting appears again on the first chatbot opening from either page.

Because the chatbot is available on the Daily Task page, it should be aware of the user's current tasks/events using the existing task/event data.

For example, if the Daily Task page contains:

* 9:00 AM – Take medication

* 5:00 PM – Pick up groceries

The chatbot should use the same existing data rather than creating duplicate task data.
