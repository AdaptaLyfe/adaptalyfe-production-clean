Redesign and fix the **Subscription section** in the existing Flutter application.

## Main Requirement

The existing **React Native + Wrapper application already has a working subscription flow using Stripe**.

I want the Flutter subscription section to have the **same subscription plans, UI behavior, business rules, access control, trial logic, and subscription experience as the existing React Native + Wrapper app**.

However, payment processing in Flutter must use the correct native store billing system:

* **Android → Google Play Billing / Google Play subscriptions**

Stripe should continue to be used only where appropriate for the existing backend/subscription architecture, entitlement synchronization, or web/payment infrastructure.

# 3. Android Subscription

For Android, implement subscription purchasing using:

**Google Play Billing**

Use Flutter's supported in-app purchase approach/package already present in the project where possible.

Before modifying dependencies:

* Check the current Flutter version.
* Check the current `in_app_purchase` dependency.
* Check Android configuration.
* Reuse the existing implementation if it already exists.
* Upgrade dependencies only when required.

Android purchase flow:

```text
Flutter Subscription UI
        ↓
Load Google Play products
        ↓
User selects subscription
        ↓
Google Play Billing
        ↓
Purchase result
        ↓
Verify purchase
        ↓
Backend subscription/entitlement update
        ↓
Refresh user subscription status
        ↓
Unlock premium features
```
