Fix the Flutter Caregiver Setup invitation flow properly. This is a recurring bug, so do NOT apply a temporary UI-only fix. Find and fix the root cause across the complete invitation, acceptance, database, state-management, and UI flow.

### BUG

When User A invites a caregiver:

1. Caregiver invitation is created successfully.
2. Caregiver receives the invitation.
3. Caregiver accepts the invitation successfully.
4. The invitation status changes to `ACCEPTED`.
5. However, the caregiver's name does NOT appear in the **"Active Caregivers"** list.
6. The same caregiver still appears in the **"Invitations"** section with status **"ACCEPTED"**.

Expected behavior:

After an invitation is accepted successfully:

* The caregiver must appear in **Active Caregivers**.
* The accepted invitation should no longer appear in the pending/invitations list.
* If the Invitations section intentionally shows invitation history, an accepted invitation may remain there as history, but it must NOT be treated as an active/pending invitation.
* Active caregiver data and invitation data must remain consistent after refresh, logout/login, app restart, and navigation.
