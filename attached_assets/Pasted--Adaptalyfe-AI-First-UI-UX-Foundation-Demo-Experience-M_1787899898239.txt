# Adaptalyfe — AI-First UI/UX Foundation + Demo Experience

## 🚨 MASTER RULE: ZERO REGRESSION + FUTURE AI FOUNDATION

Build a **high-fidelity, demo-ready, production-quality UI/UX foundation** for Adaptalyfe's next-generation AI-first Task, Event, Routine and Independence experience.

This UI will be used for:

1. The upcoming product demo
2. Future real AI feature development
3. Future AI Guide intelligence
4. Future contextual recommendations
5. Future task/event automation
6. Future personalization and independence workflows

Therefore, **DO NOT build this as a temporary throwaway prototype.**

Build the UI as a **reusable product foundation** that can initially run with existing data and isolated demo/mock states, but can later connect to real AI services without requiring a complete UI redesign.
