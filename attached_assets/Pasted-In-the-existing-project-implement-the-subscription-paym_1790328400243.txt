Implement the same functionality in Flutter:

#### Android

Use **Google Play Billing / Google Play subscriptions**.

#### iOS

Use **Apple App Store / StoreKit subscriptions**.

* Android → Google Play
* iOS → Apple App Store

Do NOT use Stripe for mobile store subscriptions unless the existing React Native + Wrapper implementation specifically requires Stripe for a separate purpose.

### Step 4 — Flutter Architecture

UI
↓
SubscriptionBloc
↓
SubscriptionRepository
↓
Platform Billing Service
↓
Google Play Billing / Apple StoreKit

Keep platform-specific billing code isolated from the UI.

Before adding/upgrading packages:

* Check the current Flutter/Dart version.
* Check existing dependencies.
* Avoid unnecessary package upgrades.
