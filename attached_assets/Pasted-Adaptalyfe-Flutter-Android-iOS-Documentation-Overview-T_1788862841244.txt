Important
The Flutter application will use the existing backend and API flow.
No new authentication backend is required.
Production API:
https://staging.getadaptalyfeapp.com/

The existing backend uses:
POST /api/login
POST /api/register
POST /api/logout
GET  /api/user
The existing login flow validates credentials, creates a session, and returns a session token and user information. The frontend stores the token for subsequent authenticated requests.

Splash Screen 

Purpose
The Splash Screen is the first screen displayed when the mobile application starts.
Responsibilities
Display application logo
Initialize application
Check locally stored session token
Validate existing session
Navigate to Login or Home
