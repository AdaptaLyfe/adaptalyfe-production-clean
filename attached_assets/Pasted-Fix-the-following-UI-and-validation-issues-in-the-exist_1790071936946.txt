### Screen

**Life Skills → Add Skill / Edit Skill → Milestone**

### Issues

1. **Current Level label is truncated**

   * Current UI shows something like:
     `Current Level (1...`
   * The complete label/value range is not visible.
   * Users cannot understand the exact allowed level range.

2. **Target Level label is truncated**

   * The label/value range is also being cut off, for example:
     `Target Level...`
   * The complete information must be visible.

3. **Validation message is truncated**

   * When an invalid Current Level or Target Level is entered, the validation/error message is partially hidden or clipped.
   * Users cannot understand the complete validation message.

Inspect the existing implementation and fix the **root UI layout issue**, not just the visible text.

* Find the widgets responsible for the **Current Level** and **Target Level** fields.

* Ensure the field/container can grow vertically when the validation message requires more than one line.
* Check for problematic `Row`, `Expanded`, `Flexible`, `SizedBox`, fixed widths/heights, `Text`, `InputDecoration`, `helperText`, `errorText`, or custom validation widgets causing the clipping.
* If the label and input are inside a `Row`, make the layout responsive so text does not get squeezed.
* Preserve the existing UI design and styling as much as possible.
* Do not reduce font size just to make the text fit.
* Do not remove useful information from the labels or validation messages.
