Fix the **"Current Streak"** issue on the Home screen of the existing Flutter application.

### Problem

On the Home screen, **Current Streak is always displayed as "0 days"**, even when the user has completed activities/tasks on consecutive days.

This looks like the streak calculation or data retrieval is not working correctly.

### Goal

Implement a proper, reliable **Current Streak calculation** using the existing app's real user activity/completion data.

### Important: Investigate Before Changing Code

Do NOT simply hardcode or force the value.

First inspect the existing codebase and identify:

1. Home screen/widget where "Current Streak" is displayed.
2. Bloc/Cubit/Provider/state responsible for Home data.

4. Firebase/Firestore/local database/API data structure containing completion information.
5. Existing date/time handling and timezone logic.
6. Whether the Home screen is actually receiving the latest completion data.

Then identify the root cause of why the value remains `0`.

### Streak Rules

Implement the streak according to these rules:

* A day counts toward the streak only when the user has at least one valid completed activity/task for that day.
* **Current Streak** means the number of consecutive qualifying days ending today.
* If the user completed something today, count today and continue checking previous consecutive days.
* If the user has not completed anything today but completed something yesterday, handle this according to the existing product behavior; if no existing behavior is defined, use the standard rule that the current streak is `0`.
* Multiple completed tasks on the same day count as **one day**, not multiple days.
* Missing any day breaks the streak.
* Future dates must never increase the streak.
* Duplicate completion records must not increase the streak.
* Use the user's actual completion date, not the record creation/update date.
* Handle timestamps consistently with the app's existing timezone/date handling.
* Do not accidentally compare full timestamps when the requirement is based on calendar days.

### Example

If completed activity dates are:

* Sep 23 → completed
* Sep 22 → completed
* Sep 21 → completed
* Sep 20 → completed
* Sep 19 → no completion

Then:

`Current Streak = 4 days`

If:

* Sep 23 → completed
* Sep 22 → completed
* Sep 21 → no completion
* Sep 20 → completed

Then:

`Current Streak = 2 days`

because Sep 21 breaks the streak.

### Edge Cases
