Fix the assignment creation/update error in the existing Flutter **Academic Planner / Student Planner** module.

### Current Issue

In:

**Academic Planner / Student Planner → Assignment**

When creating a new assignment or updating an existing assignment, the user can enter **Estimated Hours** as a decimal value, for example:

* `2.5`
* `1.5`
* `0.5`
* `3.75`

When a decimal value such as **2.5 hours** is entered, the app shows:

**"Failed to create assignment"**

or

**"Failed to update assignment"**

The assignment is not successfully saved.

### Required Fix

Fix the issue so that **Estimated Hours supports decimal values correctly**.

For example:

**Create Assignment**

* Estimated Hours: `2.5`
* Assignment should be created successfully.

**Update Assignment**

* Existing Estimated Hours: `2.0`
* Change to `2.5`
* Assignment should update successfully.

Also support normal integer values such as `1`, `2`, `3`, etc.
