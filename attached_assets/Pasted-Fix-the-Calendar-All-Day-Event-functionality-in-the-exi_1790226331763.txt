Fix the Calendar "All Day Event" functionality in the existing Flutter application.

### Current Bug

When creating a calendar event:

1. User selects a date.
2. User enables the **"All day event"** toggle.
3. User saves the event.
4. The event is not displayed correctly in the **All Day** section for the selected date.

There is also confusion between:

* **Whole Day** = event is for one complete selected date.
* **All Day / Repeating All Day** = event should continue/repeat for all days starting from the selected date, based on the existing app's intended behavior.

### Required Behavior

Implement the correct behavior without breaking the existing calendar functionality.

#### 1. Whole Day Event

If the event is intended to cover only the selected date:

* Show the event on the selected date.
* Display it as **"Whole Day"**.
* It must NOT appear on other dates.
* It must be treated as a single-day event.

#### 2. All Day Event

When the user enables the **"All day event"** toggle:

* The event must be saved with the correct all-day information.
* It must appear in the Calendar's **All Day** section.
* It must start from the user's selected start date.
* If the existing application defines this option as a repeating all-day event, ensure it is displayed on every applicable day starting from the selected date according to the existing recurrence configuration.
* Do not convert it into a timed event.
* Do not require a start/end time for an all-day event.
