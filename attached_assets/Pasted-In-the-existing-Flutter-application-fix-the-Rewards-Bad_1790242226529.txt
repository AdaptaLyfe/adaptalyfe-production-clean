In the existing Flutter application, fix the **Rewards → Badges** feature completely.

### Current Problem

On:

**Rewards → Badges**

the app shows:

> "No badges yet"

even when the user has:

* Redeemed rewards multiple times
* Earned reward points
* Achieved multiple milestones

Because of this, it is unclear whether the Badges feature is actually working.

There is also no clear/exact flow explaining:

* What badges are available
* How a user earns each badge
* What action/milestone triggers a badge
* Whether a badge was earned but not displayed
* What progress is required for the next badge

The previous fixes have reopened this bug multiple times. **Do not apply a temporary UI fix. Investigate and fix the complete badge data flow.**
