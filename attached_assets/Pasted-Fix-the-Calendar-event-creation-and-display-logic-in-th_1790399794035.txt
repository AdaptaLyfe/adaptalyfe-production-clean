Fix the Calendar event creation and display logic in the existing Flutter application.

### Current Issue

In the Calendar screen, when creating an event:

* User enables the **"All day event"** toggle.
* Selects a date.
* Saves the event.
* The event is NOT displayed correctly as an all-day event on the selected date.

The all-day event behavior needs to be fixed properly.

### Required Behavior

#### 1. All-day event = ON

When the user enables **"All day event"**:

* The event must be saved as an all-day event.
* It must appear in the **All Day** section of the calendar.
* It must appear on the **selected start date**.
* It should not depend on a start/end time.
* Do not display it as a timed event.
* When the user closes and reopens the Calendar screen, the event must still appear correctly.
* When the app is restarted, the event must still appear correctly.

#### 2. Whole Day vs All Day

Handle these two concepts correctly:

**Whole Day**

* If the event is intended to cover the complete selected day only, display the label **"Whole Day"**.
* It should belong only to the selected date.

**All Day**

* If the **"All day event"** toggle is enabled, treat it as an all-day calendar event.
* The event should start from the selected date and remain an all-day event according to its configured date range.
* Do not incorrectly convert it into a timed event.
