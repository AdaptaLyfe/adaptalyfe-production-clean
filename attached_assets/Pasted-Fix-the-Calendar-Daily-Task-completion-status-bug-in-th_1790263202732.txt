Fix the **Calendar Daily Task completion status bug** in the existing **React Native + Wrapper** application.

### Bug

When a user completes a Daily Task:

* The **Task List** correctly shows the task as **Completed**.
* But in the **Calendar**, the same task is still shown as **Not Completed / Incomplete**.
* The bug has been fixed before but keeps coming back, so do NOT apply only a UI-level workaround.

### Goal

Make the Daily Task completion status **consistent everywhere in the application**, especially between:

1. Daily Task List
2. Calendar
3. Task Details, if applicable
4. Any other screen that displays the task's completion status

### Important: Find the ROOT CAUSE

Before changing code:

1. Trace the complete Daily Task data flow:

   * Task creation
   * Task fetching
   * Task list state
   * Task completion/update API or database operation
   * Local state/store/cache
   * Calendar data source
   * Calendar completion rendering

2. Identify why the Task List receives the updated `completed` status but Calendar does not.

3. Check whether Calendar is:

   * Using a different API/query
   * Using stale state
   * Using cached task data
   * Using a different completion field
   * Comparing the wrong date
   * Comparing timestamps incorrectly
   * Using different task IDs
   * Maintaining its own outdated completion state

### Completion Status

Find the actual source of truth for task completion.

Do NOT maintain separate independent completion states for Task List and Calendar.

If the backend/database contains something like:

```text
completed
isCompleted
status
completedAt
```

determine which field is the actual source of truth and make Calendar use the same source.

### Date Handling

Carefully verify date matching.

A completed task must remain completed for the correct calendar date.

Check for:

* UTC vs local time
* Timezone conversion
* `Date` vs timestamp/string comparison
* Different date formats
* Time included in one value but not another
* Start/end-of-day calculations
* Off-by-one-day issues

Do not fix this by simply changing the displayed date.

### State Management

After a user completes a task:

1. Update the actual task completion state.
2. Update/invalidate the relevant cache if caching is used.
3. Refresh or synchronize Calendar data.
4. Ensure navigation between Task List and Calendar does not restore stale data.
5. Ensure reopening the Calendar shows the correct completion state.
6. Ensure app refresh/reload still shows the correct status.

If React Query, Redux, Context, Zustand, MobX, AsyncStorage, or another state/cache system is being used, inspect the existing implementation and update the correct cache/state instead of creating another state variable.

### Do NOT

* Do not create a fake Calendar-only `completed` flag.
* Do not hardcode completed tasks.
