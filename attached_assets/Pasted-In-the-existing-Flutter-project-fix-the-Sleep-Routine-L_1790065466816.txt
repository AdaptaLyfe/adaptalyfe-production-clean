In the existing **Flutter project**, fix the **Sleep Routine → Log Sleep** functionality.

### Problem

On the **Log Sleep** screen, the user currently has fields such as:

* Sleep Date
* Bed Time
* Time Fell Asleep
* Wake Time

There is currently **no Wake Date** field.

Because of this, the app incorrectly assumes that the Wake Time belongs to the same date as the Sleep Date.

Example:

* Sleep Date: September 22
* Bed Time: 10:00 PM
* Time Fell Asleep: 10:30 PM
* Wake Time: 8:00 AM

The app currently compares `8:00 AM` with `10:30 PM` on the same date and shows an error such as:

> Wake time cannot be earlier than sleep time.

This is incorrect because **8:00 AM means the next morning, September 23**.

---

## Required Fix

Add a new field:

**Wake Date**

Place it beside or directly before/after the **Wake Time** field so the relationship is visually clear.

The Log Sleep form should now contain:

* Sleep Date
* Bed Time
* Time Fell Asleep
* Wake Date
* Wake Time

Use the existing Flutter date/time picker design and styling wherever possible. Do not unnecessarily redesign the screen.

---

## Correct Date/Time Logic

The application must compare **complete DateTime values**, not only the time portion.

For example:

### Valid Case 1 — Sleep at night, wake next morning

Sleep Date:
`September 22`

Time Fell Asleep:
`10:30 PM`

Wake Date:
`September 23`

Wake Time:
`8:00 AM`

Result:

**Allowed**

Because:

`September 23, 8:00 AM > September 22, 10:30 PM`

---

### Valid Case 2 — Same-day sleep and wake

Sleep Date:
`September 22`

Time Fell Asleep:
`2:00 PM`

Wake Date:
`September 22`

Wake Time:
`5:00 PM`

Result:

**Allowed**

Because the wake DateTime is after the sleep DateTime.

---

### Invalid Case — Wake before sleep on the same date

Sleep Date:
`September 22`

Time Fell Asleep:
`10:00 PM`

Wake Date:
`September 22`

Wake Time:
`9:00 PM`

Result:

**Not allowed**

Show the existing validation error/message indicating that wake time/date must be after sleep time/date.

---

### Invalid Case — Wake Date before Sleep Date

Sleep Date:
`September 22`

Time Fell Asleep:
`10:00 PM`

Wake Date:
`September 21`

Wake Time:
`8:00 AM`

Result:

**Not allowed**

The Wake DateTime cannot be before the Sleep/Fell Asleep DateTime.

---

## Important Validation Rule

The primary validation should be:

```text
Wake DateTime > Fell Asleep DateTime
```

Do NOT validate using only:

```text
wakeTime > sleepTime
```

because that causes the overnight sleep bug.

The comparison must include both:

```text
Date + Time
```

for both sleep and wake.
