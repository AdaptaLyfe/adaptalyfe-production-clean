In the existing Flutter application, fix the crash/error in:

**Health Record → Healthcare Contact → Edit → Update Contact**

### Current Issue

When the user edits an existing Healthcare Contact and clicks **"Update Contact"**, the following errors occur:

```text
Tried to build dirty widget in the wrong build scope.
'package:flutter/src/widgets/framework.dart':
Failed assertion: line 6065 pos 14: '_dependents.isEmpty': is not true.

A TextEditingController was used after being disposed.
```

### Task

Investigate the existing Healthcare Contact edit/update flow and identify the root cause of these errors.

The most important issue to investigate is the **TextEditingController lifecycle**. Check whether any `TextEditingController` is being:

* Disposed while the widget is still using it.
* Reused after `dispose()`.
* Created inside a widget/build method and incorrectly disposed.
* Shared between multiple widgets/screens and disposed by one of them.
* Passed to a child widget that continues using it after the parent has been disposed.
* Disposed when navigating back or after the update operation while the widget is still rebuilding.

Also investigate the **widget/build lifecycle** causing:

```text
Tried to build dirty widget in the wrong build scope.
```

Check for:

* `setState()` being called after widget disposal.
* `setState()` or state updates during the widget's build phase.
* Async update operations completing after the widget has been disposed.
* Navigation happening while the widget is rebuilding.
* Provider/BLoC/state listeners triggering updates after the screen has been removed.
* Controllers or listeners being disposed too early.
* `addListener()` callbacks remaining active after disposal.
* Any `BuildContext` being used after an async operation without checking widget lifecycle.
